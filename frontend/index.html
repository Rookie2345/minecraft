How to Connect (Java Guide)
  1. Open your Minecraft Java Edition launcher (e.g., TLauncher or Official Launcher).
  2. Select version 26.3 and launch the game.
  3. From the main menu, click on Multiplayer.
  4. Click Add Server. Enter a server name (e.g. Our Community Server).
  5. Paste the Server Address displayed above and click Done.
  6. Select the server and click Join Server to enter!

How to Connect (Bedrock & Android)
  1. Launch Minecraft Bedrock on your Android or supported device.
  2. Tap the Play button on the title screen.
  3. Select the Servers tab from the top navigation.
  4. Scroll down to the bottom of the list and tap Add Server.
  5. Enter any Server Name (e.g. Community Bedrock).
  6. Paste the Server IP / Address and Port shown above separately into the corresponding fields.
  7. Tap Save or Play to connect!
